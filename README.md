# jams

> **Archived.** This project is unmaintained (no activity since 2020).

jams was a small quality checker for repositories: it fetched a repo's README
via the GitHub API and checked title formatting, required sections, broken
links, and misspellings, plus Dockerfile, root-file and language-specific
(Go/Python) checks, and produced an overall quality score.

Alternatives:

- GitHub Community Standards — built-in repository health score
- [repolinter](https://github.com/the-ossfirm/repolinter) — rule-based repository linter
- [markdown-link-check](https://github.com/tcort/markdown-link-check) — broken link checking for Markdown
